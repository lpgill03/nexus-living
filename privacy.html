Privacy Policy

Nexus Living · effective 6 October 2026

Who uses this application

Nexus Living is a private application operated by its owner for their own use only. It is not distributed to, and cannot be used by, anyone else. The only Google account it accesses is the owner's own.

What data it accesses

With the owner's consent, the application uses the Gmail API (scope gmail.modify) to read, send and organise messages in the owner's Gmail account, for example to deliver automated notification emails to the owner.

How data is used and stored

  • Data is processed on the owner's own computer. No message content is sent to, or stored on, any third-party server.
  • OAuth tokens are stored locally on the owner's computer and are used only to call Google APIs on the owner's behalf.
  • No data is sold, shared, or used for advertising, profiling, or any purpose other than the owner's own automation.

Google API Services User Data Policy

Nexus Living's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from Google Account → Security → Third-party apps & services, which invalidates the stored tokens.
